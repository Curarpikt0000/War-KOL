## 名册怎么来的（不是拍脑袋）

### 四维加权评分

| 维度 | 权重 | 判据 |
|---|---|---|
| A 机构与专业根基 | 30% | 智库/军方/情报/学术任职；同行评审出版物；被主流机构引用或聘为专家 |
| B 一手性 | 25% | 自采数据、卫星影像判读、战场影像地理定位、官方文件与预算解析 = 高；转引二手 = 中；纯口播评论 = 低 |
| C 历史命中率 | 30% | 过去公开预测 vs 实际结果的对照证据；有无被公开证伪的重大错误；有无主动更正记录 |
| D 方法透明度 | 15% | 是否逐条给信源链接；是否区分「已证实/未证实/推测」；是否公开更正错误 |

### 星级 = 群体内百分位

前10%=5★ / 10-30%=4★ / 30-60%=3★ / 60-85%=2★ / 其余=1★

**不用绝对切点**——「命中率 30% 算好算坏」没有客观答案，相对位次才可解释。

### 入库门槛

**只收 3★ 及以上。** 123 位候选 → 62 人入库，落选者留痕备查。

两处明示的破例：
- **南亚放宽至 2★**：该战区达 3★ 者仅 2 人。这是结构性的——区域战地型分析者
  在「机构根基」「方法透明度」两维天然吃亏，即便是该领域最权威者也卡在 2★。
  放宽补至 5 人，卡片标「区域代表·评分较低」。
- **监测对象（watchlist）**：指定纳入的低可信度信源，**不占 3★ 名额**，
  卡片显示「低可信度·需交叉验证」警示。其言论不得作为事实陈述转述。

## 数据纪律

- **绝不编造**。抓不到就标 `status=not_found`，不臆造言论/日期/出处。
- 每条言论锚 `source_url`，可追溯。
- **发表日按 KOL 实际发表日**，查不到留空标 `date_status=unverified`，
  绝不用抓取日顶替。
- **归属校验**：检索引擎对中文名/音译名会退化成主题搜索，抓回与本人无关的文章
  甚至同名者主页。所有条目须通过归属校验（自有平台域名 or 正文含姓名）才入库，
  被拒条目留痕在 `rejected_attribution.jsonl`。
- **争议如实标注**：KOL 若有被公开证伪、被要求删帖的记录，必须写进 `controversies`
  并在卡片显示。既不因履历漂亮免检，也不因有争议一票否决——按证据打分。

## 自动化

| 任务 | 频率（JST） | 内容 |
|---|---|---|
| daily | 每日 09:00 | 镜像名册 → 抓取 → 写 Notion → 建看板 → 发布 → 日报 |
| weekly | 周六 09:00 | 一周立场**转向**汇总 |
| monthly | 每月 1 日 09:00 | 月度走势 + **预测应验判定**（hit/miss/unclear） |
| selfheal | 每小时 :35 | 自愈 watchdog，正常静默 |

预测应验只判**已到期**者，表述模糊无法客观验证的一律 unclear，**不强判**。
